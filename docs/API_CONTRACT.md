# API contract (shared by ML, backend and frontend)

Class IDs are exactly the folder names in `models/class_names.json` (e.g. `Pepper__bell___healthy`). Header `X-Session-Id` (8-64 chars `A-Za-z0-9_-`, generated by the frontend) scopes history to a browser. Errors: `{"detail": "message"}`.

## POST /api/predict (multipart/form-data)
Fields: `file` (JPEG/PNG, <= 8 MB, required); optional `crop` (Tomato|Potato|Pepper), `temperature_c` (-30..60), `humidity_pct` (0..100), `rainfall_mm` (>=0), `soil_moisture` (0..1), `latitude`, `longitude`.
Response 200 (same shape as `GET /api/scans/{id}`):
```json
{
  "scan_id": 12, "created_at": "2026-11-01T09:20:11+00:00",
  "predicted_class": "Tomato_Late_blight", "display_name": "Tomato - Late blight", "crop": "Tomato",
  "selected_crop": null, "is_healthy": false, "confidence": 0.93,
  "top3": [{"class": "Tomato_Late_blight", "display_name": "...", "confidence": 0.93}],
  "model_version": "mobilenetv2_final", "low_confidence": false, "warnings": [],
  "note": "confidence is a softmax score, not a calibrated probability",
  "image_url": "/files/uploads/<uuid>.jpg", "environment": null, "risk": null,

}
```
Status: 400 invalid image, 413 too large, 415 wrong type, 422 bad field, 503 model not trained.

## GET /api/explain/{scan_id}
Generates (once) and returns Grad-CAM: `overlay_url`, `heatmap_url`, `original_url`, `gradcam_info {main_region, coverage_pct}`, `explanation`. 501 if the loaded model is not MobileNetV2.

## Scans
`GET /api/scans?q=&crop=&status=healthy|diseased&sort=date_desc|date_asc|conf_desc|conf_asc&limit=&offset=` -> `{total, items[]}`; `GET /api/scans/{id}`; `DELETE /api/scans/{id}` -> 204.

## Weather (Open-Meteo)
`GET /api/weather/geocode?q=` · `GET /api/weather?lat=&lon=` (current, 7-day daily with per-day rule-based risk) · `GET /api/weather/history?lat=&lon=&start=YYYY-MM-DD&end=YYYY-MM-DD` (<= 92 days, end >= 2 days ago). 502 on upstream failure.

## Rule-based tools
`POST /api/simulator` `{baseline:{...}, scenario:{...}}` -> both assessments, `factor_changes`, `summary`.
`POST /api/recommendations` `{predicted_class, confidence, selected_crop?, environment?}`.
`POST /api/chat` `{message, scan_id?, history[]}` -> `{reply, topic, mode}`.

## Analytics / reports / satellite
`GET /api/analytics/summary?date_from=&date_to=&crop=` · `GET /api/analytics/export` (CSV) · `GET /api/reports/{id}` (PDF) · `GET /api/satellite/status` · `POST /api/satellite/indices` `{latitude, longitude, start_date, end_date, radius_m, max_cloud_pct}` (503 if Earth Engine is not configured).
